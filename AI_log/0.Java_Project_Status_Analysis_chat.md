### Why Podman Was Stuck Pulling

Podman encountered an unqualified short image name (`eclipse-temurin:17-jdk-alpine`) and paused for an interactive prompt on `stdin`:

```text
? Please select an image:
  ▸ registry.fedoraproject.org/eclipse-temurin:17-jdk-alpine
    registry.access.redhat.com/eclipse-temurin:17-jdk-alpine
    docker.io/library/eclipse-temurin:17-jdk-alpine
```

In a non-interactive shell, Podman hangs indefinitely waiting for input. Prefixing the registry (`docker.io/library/eclipse-temurin:...`) avoids the prompt completely.

### Container Added

Created [Containerfile](file:///home/henius/Downloads/voucher-service-takehome/voucher-service/Containerfile) and [.dockerignore](file:///home/henius/Downloads/voucher-service-takehome/voucher-service/.dockerignore) in `voucher-service`.

- **Stage 2 (Runtime)**: `docker.io/library/eclipse-temurin:17-jre-alpine` runs `app.jar` as non-root user `appuser`.
- **Exposed port**: `8080`.

### How to Use

#### 1. Build Image

```bash
cd voucher-service
podman build -t voucher-service -f Containerfile .
```

#### 2. Run Container

```bash
podman run -d --rm --name voucher-service -p 8080:8080 localhost/voucher-service:latest
```

#### 3. Verify

```bash
curl -s http://localhost:8080/campaigns/1/stats
```

#### 4. Stop

```bash
podman stop voucher-service
```

#### 5. Run Gradle Tests via Podman (No Local Java Required)

```bash
podman run --rm -v "$(pwd)/voucher-service":/app:z -w /app docker.io/library/eclipse-temurin:17-jdk-alpine sh ./gradlew test
```
