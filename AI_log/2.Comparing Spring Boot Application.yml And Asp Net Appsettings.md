## Antigravity

**Yes.** [application.yml](file:///home/henius/Downloads/voucher-service-takehome/voucher-service/src/main/resources/application.yml) serves the exact same purpose as `appsettings.json` in ASP.NET Core.

### Direct Comparison

| Feature                    | Spring Boot                                              | ASP.NET Core                                                           |
| :------------------------- | :------------------------------------------------------- | :--------------------------------------------------------------------- |
| **Main Config**            | `application.yml` (or `.properties`)                     | `appsettings.json`                                                     |
| **Environment Profile**    | `application-{profile}.yml` (e.g. `application-dev.yml`) | `appsettings.{Environment}.json` (e.g. `appsettings.Development.json`) |
| **Env Var Overrides**      | `SPRING_DATASOURCE_URL` (relaxed binding)                | `ConnectionStrings__DefaultConnection`                                 |
| **Value Injection**        | `@Value("${key.name}")`                                  | `Configuration["key:name"]`                                            |
| **Strongly-typed Binding** | `@ConfigurationProperties` class                         | `IOptions<T>` pattern                                                  |

---

## Antigravity

Primitive `int` cannot hold `null`.

### Reason

1. **JPA SQL `NULL` mapping**: When Hibernate reads a SQL `NULL` into a primitive `int`, it converts `NULL` to `0`.
2. **False limit trigger**: If mapped to `0`, `count >= 0` evaluates to `true` on the very first attempt and blocks every user (`"User redemption limit reached"`).
3. **Detection of missing value**: Boxed [`Integer`](file:///home/henius/Downloads/voucher-service-takehome/voucher-service/src/main/java/com/prizm/campaign/model/Campaign.java#L26) holds `null`, allowing [`VoucherService`](file:///home/henius/Downloads/voucher-service-takehome/voucher-service/src/main/java/com/prizm/campaign/service/VoucherService.java#L60) to detect that no DB limit was configured and fall back to `defaultPerUserLimit`.
